# rhis-satellite-kickstart (infra-satellite-ks)

Self-contained OEMDRV kickstart generator for a Red Hat Satellite server on RHEL 9.

Upstream components are vendored so the tree works **offline after clone** — just install Ansible collections while you still have network.

| Component | Upstream | Commit |
|-----------|----------|--------|
| `kickstart-generator/` | [rhis-builder-bootstrap-init](https://github.com/parmstro/rhis-builder-bootstrap-init) | `3ded8886` |
| `inventory-generator/` | [rhis-builder-inventory](https://github.com/parmstro/rhis-builder-inventory) | `69245a9b` |

See [VENDORED.md](VENDORED.md) for update instructions.

## Prerequisites

- RHEL 9 (or Fedora) with `ansible-core` 2.14+
- `community.general` Ansible collection (7.0+)
- Root or sudo access on the provisioner
- Active Red Hat subscription with CDN organization ID and activation key for RHEL 9 minimal
- SSH key pair for the automation user (`ansiblerunner`)

## Quick start

```bash
git clone https://github.com/rathbunr/infra-satellite-ks.git
cd infra-satellite-ks

# One-time setup
ansible-galaxy collection install -r kickstart-generator/requirements.yml
./scripts/setup.sh

# Edit the three configuration files
#   environment.conf                                                — domain, paths
#   kickstart-generator/group_vars/provisioner/satellite_init_vars.yml  — host details
#   ~/.rhis-vault/rhis_builder_vault.yml                            — passwords, keys

# Generate encrypted passwords and fill the vault
./scripts/generate-passwords.sh
ansible-vault encrypt ~/.rhis-vault/rhis_builder_vault.yml

# Optional: generate full deployment inventory (for later rhis-provisioner use)
./scripts/generate-inventory.sh

# Generate the kickstart
./scripts/generate-kickstart.sh          # USB method
./scripts/generate-kickstart.sh --iso    # ISO virtual media method
```

## Kickstart delivery methods

| Method | When to use | Flag |
|--------|-------------|------|
| **USB** | Lab — physical access to the server | (default) |
| **ISO virtual media** | Datacenter — iDRAC, iLO, Redfish | `--iso` (and set `generate_oemdrv_iso: true` in vars) |
| **Disconnected** | Air-gapped — no internet on target | Set `disconnected: true` in host entry |

See [docs/kickstart-delivery.md](docs/kickstart-delivery.md) for details.

## What happens after the kickstart

Once the Satellite node is installed and reachable via SSH, use the [rhis-provisioner container](https://github.com/parmstro/rhis-provisioner-container) to configure IdM, Satellite, and AAP. Launch scripts are generated by `inventory_update.sh` in `inventory-generator/deployments/<domain>/`.

## Project structure

```
├── config/                     # Configuration templates (.sample files)
├── kickstart-generator/        # Vendored bootstrap-init (Ansible role + playbook)
│   ├── main.yml                # Top-level playbook
│   ├── inventory/hosts         # Localhost provisioner inventory
│   └── roles/bootstrap_init/   # Full role (tasks, templates, defaults)
├── inventory-generator/        # Vendored inventory engine
│   ├── inventory_update.sh     # Main entry point
│   ├── inventory_template/     # Jinja2 templates for deployment generation
│   └── inventory_update_subtasks/
├── scripts/                    # Setup and wrapper scripts
└── docs/                       # Workflow, delivery methods, variable reference
```
